## Testing & Deployment

This app is automatically deployed to GitHub Pages via GitHub Actions when changes are pushed to the master branch. The deployment workflow:

1. Builds and packages the entire repository
2. Deploys to GitHub Pages at https://mazzu001.github.io/CrossUI-Empty
3. The app loads CrossUI libraries from the official CDN

To test locally, serve the files through a web server (not file:// protocol) to allow proper loading of external resources.
